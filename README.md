DOWNLOAD GUIDE FOR WINDOWS
To download a version of the game go to releases and click on any version
Then click on the "Assets" Button and download the file that reads:
"VOTN_alpha #.#.#.zip" (#=version number)
Once downloaded, right click the zip file and press extract all
When its done extracting, left click the folder that reads:
"VOTN_alpha #.#.#"
Then left-click the next folder in the folder you just clicked and you should see:
_internal <-- Contains all the game assets, please do not edit
README.txt <-- Just some extra text and use rights
LICENSE.txt <-- License saying use rights and where the game should be downloaded from 
VOTN_alpha #.#.#.exe <-- This is the game file, double click to launch
When you launch the .exe file, a blue screen will probably pop up saying:
"Windows Smartscreen protected your PC"
That is just the computer saying it doesn't trust the game file
Just click "More info" And then "Run anyway" to succesfully launch the game
